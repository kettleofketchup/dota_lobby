# Changelog

All notable changes to this project are documented here.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

Do not edit this file in a PR: add a fragment under `changelog.d/` (see its README).
Releases are cut from `main` with `just release::hotfix|upgrade|major`, which assembles the
fragments into a new `## [X.Y.Z]` section, tags `vX.Y.Z` and pushes. `release.yml` then
publishes the GitHub Release and `container.yml` the image. See
`.claude/skills/changelog/SKILL.md`.
